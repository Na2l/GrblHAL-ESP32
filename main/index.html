Steps / backlash test

Moves the axis +D then −D and reports the commanded (DRO) positions. Important: the controller counts steps (open loop), so the DRO always returns to the start — the real accuracy must be measured with a caliper / dial indicator.
• Steps/mm: measure how far the axis really travelled (+D) → if it differs from D, correct steps/mm.
• Backlash: after the return move, measure the remaining gap at the reference point → that gap is backlash.
